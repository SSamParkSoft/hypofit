# Security Policy

Hypofit is a private commercial product operated by Contentruck.

## Supported Release Line

| Release line | Status |
| --- | --- |
| `1.0.x` | Supported |
| historical iOS `1.0.0` baseline | Not the current fix target |

The current security fix target is the active `1.0.x` line. The historical
iOS `1.0.0` note is recorded for release context only.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately to:

- `ssamso8282@gmail.com`

Do not open a public GitHub issue for security-sensitive reports.

Include the smallest practical set of details needed to reproduce and assess
the issue:

- affected surface: `web`, `mobile`, `api`, or deployment
- reproduction steps
- expected behavior
- actual behavior
- impact
- screenshots, logs, request IDs, or traces if available

If the report is valid, we will handle follow-up privately and coordinate the
fix and disclosure timing directly.
