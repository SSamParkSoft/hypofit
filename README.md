## 누구를 위한 서비스인가요?

| 창업자 | 인터뷰어 |
| --- | --- |
| 타깃 고객을 모집하고 지원자를 검토합니다. | 조건을 확인하고 적합한 인터뷰에 지원합니다. |
| 채팅으로 일정을 조율하고 진행 상태를 관리합니다. | 선정 결과를 확인하고 인터뷰 일정을 조율합니다. |

한 계정으로 두 역할을 함께 이용할 수 있습니다.

## 주요 기능

- **모집과 탐색**: 모집글 작성, 검색, 필터와 지도 탐색
- **지원과 선정**: 지원 정보 확인, 선정 결과와 진행 상태 관리
- **채팅과 알림**: 일정 조율, 상태 변경과 새 메시지 안내
- **신뢰와 안전**: 신고, 차단, 문의와 계정 관리
