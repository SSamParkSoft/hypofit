# README 앱 화면 자산

루트 `README.md`에서 Hypofit의 실제 제품 화면을 보여주기 위한 공개 이미지입니다.

## 출처

- 앱: 하이포핏
- App Store ID: `6775675046`
- 공개 버전: `1.0.0`
- App Store 공개일 기준 화면 확인: 2026-08-12
- 앱 페이지: `https://apps.apple.com/kr/app/id6775675046`

`app-screens/`의 이미지는 Apple의 공개 iTunes Lookup 응답에 포함된 App Store 스크린샷을 README 표시
용도로 내려받은 것입니다. 스토어 심사에 사용된 공개 데모 화면이므로 실제 사용자 개인정보나 개발용
디버그 상태를 포함하지 않습니다.

## 갱신 규칙

- README에는 실제 출시 앱 또는 출시 후보 빌드의 화면만 사용합니다.
- 개인 이메일, 전화번호, 실제 대화와 위치가 포함된 캡처는 사용하지 않습니다.
- 주요 정보 구조나 브랜드가 달라지면 App Store 자산과 README 화면을 함께 갱신합니다.
- 앱 화면을 임의로 합성해 구현되지 않은 기능처럼 보이게 하지 않습니다.
- App Store 다운로드 배지는 `apps/web/public/brand/download-on-app-store.svg`의 공식 자산을 변형하지
  않고 사용합니다.
- Google Play 공개 URL이 생기기 전에는 동작하지 않는 다운로드 배지를 추가하지 않습니다.
